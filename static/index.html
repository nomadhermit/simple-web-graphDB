Regex filter help

Use regex on the Label or Attribute value filters.

Syntax
  • pattern — compiled as /pattern/i (case-insensitive by default)
  • /pattern/flags — explicit form; flags: i ignore case, m multiline, s dotall, u unicode, g ignored for test
Common tokens
.any character except newline
\d \w \sdigit, word char, whitespace
\D \W \Snot digit / word / space
^ $start / end of string
* + ?0+, 1+, 0 or 1
{n} {n,m}exactly n, or n to m
[abc] [^abc]char class / negated
(a|b)alternation (group)
\.literal dot (escape special chars)
Examples
^Orderlabel/value starts with “Order”
item$ends with “item”
open|closedcontains “open” or “closed”
^\d{3}$exactly 3 digits
/[A-Z]{2,}/2+ uppercase letters (case-sensitive)
/status$/iends with “status”, ignore case
^(?!draft).*does not start with “draft”

Invalid patterns show an error and the query does not run. Attribute modes key exists / key does not exist ignore the value field.
